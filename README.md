# Система учёта договоров аренды и лизинга спецтехники

## 📋 Описание проекта
WPF-приложение для ИП «Апоста А.В.» (аренда спецтехники) для централизованного учёта договоров аренды/лизинга.

## 🛠️ Технологический стек
- **Платформа**: .NET Framework 4.7.2
- **UI-фреймворк**: WPF с XAML-разметкой
- **Архитектура**: MVVM (INotifyPropertyChanged)
- **СУБД**: Microsoft SQL Server 2019+
- **ORM**: Entity Framework 6 (Database-First)
- **IDE**: Visual Studio 2022
- **Язык**: C# 7.3+

## 🗄️ Структура проекта

### Модели данных (Models/)
- `Enums.cs` - перечисления AssetGroup, VehicleSubcategory, EquipmentSubcategory, ContractType, ContractStatus
- `Counterparty.cs` - модель контрагента
- `Asset.cs` - модель техники/оборудования
- `Contract.cs` - модель договора
- `ContractSpecification.cs` - модель спецификации договора
- `PaymentSchedule.cs` - модель графика платежей

### Архитектура MVVM
- `ViewModelBase.cs` - базовый класс с INotifyPropertyChanged
- `MainViewModel.cs` - главный ViewModel

### WPF интерфейс
- `App.xaml/.cs` - точка входа WPF приложения
- `MainWindowSimple.xaml/.cs` - упрощенное главное окно
- `MainWindow.xaml/.cs` - главное окно со стилями (требует доработки)
- `ContractsView.xaml/.cs` - представление для договоров

## 🚀 Запуск проекта

### Способ 1: Visual Studio 2022
1. Откройте файл `ForVlad.csproj` в Visual Studio 2022
2. Убедитесь, что выбран .NET Framework 4.7.2
3. Нажмите F5 для запуска

### Способ 2: Командная строка
```bash
# Используйте MSBuild из Visual Studio
MSBuild ForVlad.csproj /p:Configuration=Debug /p:Platform="Any CPU"
```

## 🔧 Текущие проблемы и решения

### Ошибка: "Предоставление значения для System.Windows.StaticResourceExtension вызвало исключение"
**Причина**: Стили определены после их использования в XAML
**Решение**: Используйте `MainWindowSimple.xaml` (упрощенная версия без стилей)

### Ошибка: "Программа не содержит статического метода Main"
**Причина**: Конфликт точек входа
**Решение**: Убедитесь, что в проекте только один файл с точкой входа (App.xaml)
