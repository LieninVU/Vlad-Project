# Быстрый старт

## 🚀 Запуск за 5 минут

### Шаг 1: Установите Entity Framework
Откройте проект в Visual Studio 2022:
1. Правой кнопкой по проекту → "Manage NuGet Packages"
2. В поиске введите "EntityFramework"
3. Установите версию 6.4.4

### Шаг 2: Создайте базу данных
1. Откройте SQL Server Management Studio или используйте командную строку
2. Выполните скрипт `create_database_simple.sql`

**Или через командную строку:**
```bash
sqlcmd -S "(localdb)\MSSQLLocalDB" -i create_database_simple.sql
```

### Шаг 3: Запустите приложение
1. В Visual Studio нажмите F5
2. В статусной строке должно появиться: "Подключение к базе данных установлено"

## 🐛 Если не работает

### Ошибка: "Не удалось загрузить файл или сборку 'EntityFramework'"
**Решение**: Установите пакет через NuGet (Шаг 1)

### Ошибка: "Не удалось подключиться к базе данных"
**Решение**:
1. Убедитесь, что SQL Server запущен
2. Проверьте базу данных: `sqlcmd -S "(localdb)\MSSQLLocalDB" -Q "USE LeasingSystemDb; SELECT DB_NAME()"`
3. Если базы нет, выполните `create_database_simple.sql`

### Ошибка компиляции
**Решение**: 
1. Build → Clean Solution
2. Build → Build Solution (Ctrl+Shift+B)
