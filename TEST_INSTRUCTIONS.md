# Инструкция по тестированию приложения

## ✅ Исправленные проблемы:

### 1. **Два окна при запуске**
**Было**: App.xaml.cs создавал окно + StartupUri создавал второе окно
**Стало**: Только StartupUri создает одно окно

### 2. **Нет переключения между вкладками**
**Было**: Кнопки меню не имели функциональности
**Стало**: Реализованы команды навигации через RelayCommand

## 🚀 Как протестировать:

### Шаг 1: Запустите приложение
- Откройте проект в Visual Studio 2022
- Нажмите F5

### Шаг 2: Проверьте навигацию
- Нажмите на кнопки в боковом меню:
  - 📋 Договоры
  - 👥 Контрагенты  
  - 🚜 Техника
  - ⚙️ Оборудование
  - 📊 Отчёты
  - ⚙️ Настройки

### Шаг 3: Проверьте отображение
- При нажатии на каждую кнопку:
  - Меняется заголовок в верхней части
  - Меняется содержимое в основной области
  - Отображается название выбранного раздела

## 🔧 Что было реализовано:

### 1. **Команды навигации**
- `RelayCommand` - класс для реализации команд
- 6 команд навигации в `MainViewModel`
- Привязка команд к кнопкам в XAML

### 2. **Динамическое отображение**
- `CurrentView` - свойство для текущего представления
- `CurrentViewTitle` - свойство для заголовка
- `SimpleView` - базовое представление для всех разделов

### 3. **Архитектура MVVM**
- Полное разделение View и ViewModel
- Привязка данных через DataContext
- Реактивное обновление интерфейса
