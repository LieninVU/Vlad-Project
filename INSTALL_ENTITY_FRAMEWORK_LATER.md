# Установка Entity Framework (отложенная)

## Текущее состояние
Проект настроен для работы с локальным хранилищем данных (`SimpleDataService`). Это позволяет:
- Компилировать и запускать проект без ошибок
- Тестировать интерфейс и навигацию
- Работать с тестовыми данными

## Когда устанавливать Entity Framework
Установите Entity Framework, когда будете готовы:
1. Подключиться к реальной базе данных SQL Server
2. Перенести данные из локального хранилища в БД
3. Использовать продвинутые функции EF (миграции, LINQ запросы и т.д.)

## Шаги для установки Entity Framework

### Шаг 1: Установка через NuGet
В Visual Studio 2022:
1. Правой кнопкой по проекту → "Manage NuGet Packages"
2. В поиске введите "EntityFramework"
3. Установите версию 6.4.4

### Шаг 2: Восстановление файлов
После установки EF, восстановите удаленные файлы:

**Data слоя:**
```csharp
// LeasingDbContext.cs - контекст базы данных
// Repository.cs - базовый репозиторий  
// UnitOfWork.cs - Unit of Work
```

**Сервисов:**
```csharp
// ContractService.cs - сервис договоров
// AssetService.cs - сервис техники
// CounterpartyService.cs - сервис контрагентов
```

### Шаг 3: Обновление конфигурации
1. Восстановите `App.config` с конфигурацией EF
2. Обновите `ForVlad.csproj` с ссылками на EF
3. Обновите `MainViewModel.cs` для использования сервисов EF

### Шаг 4: Создание базы данных
Выполните SQL скрипт `create_database_simple.sql`

## Альтернативный подход: Постепенная миграция

### Фаза 1: Локальное хранилище (текущее)
- Проект компилируется и работает
- Данные хранятся в памяти
- Идеально для разработки UI

### Фаза 2: Гибридный режим
- Добавить Entity Framework
- Сохранить `SimpleDataService` как fallback
- Постепенно переносить функциональность

### Фаза 3: Полный переход на EF
- Удалить `SimpleDataService`
- Использовать только EF сервисы
- Подключиться к production БД

## Преимущества текущего подхода

1. **Нет зависимостей** - проект работает без установки EF
2. **Быстрый запуск** - не нужно настраивать БД
3. **Простота отладки** - данные в памяти, легко тестировать
4. **Гибкость** - можно добавить EF позже

## Что делать сейчас

1. **Тестируйте интерфейс** - проверьте навигацию, команды
2. **Разрабатывайте UI** - создавайте формы для CRUD операций
3. **Добавляйте бизнес-логику** - в `SimpleDataService`
4. **Когда будет готово** - установите EF по инструкции выше

## Файлы для восстановления
Все удаленные файлы EF находятся в папке `LeasingSystem/` в корне репозитория. Скопируйте их обратно когда будете устанавливать EF.
